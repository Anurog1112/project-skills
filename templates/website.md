# Selected layout — Website

Use for a landing page, information site, portfolio, event, or service introduction. This is a layout blueprint to adapt to the requested screen and existing content.

## Structure

- Header with identity, useful navigation, and the primary action when appropriate.
- First screen that identifies the audience, explains the offer, and shows what the visitor can do next. Use an available image only when it supports that message.
- Main sections that answer the visitor's actual questions, such as benefits, how it works, examples, content, or an offer. Choose sections from the brief.
- An action section, form, or contact route that works through the intended flow.
- Footer with the available ownership and contact information.

## Design and behavior

Use a readable content width, a clear headline/body scale, coherent spacing, and responsive content groups. Keep the primary action visually identifiable. Anchor links and mobile navigation should reach the correct content and remain keyboard usable.

Use supplied facts for prices, dates, examples, and claims. Include testimonials or statistics only when the user provides them. If the task improves an existing section, preserve the surrounding site and navigation.

## User checks

- A visitor can explain the offer and find the requested action.
- The main action works and gives useful feedback.
- Navigation, long content, and forms remain usable on phone and desktop.
