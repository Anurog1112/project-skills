# Project Skills

ชุดคำแนะนำสำหรับสั่ง AI บนแพลตฟอร์มเขียนเว็บผ่านแชท โดยให้ AI ดาวน์โหลดและสร้างไฟล์ Markdown ในโปรเจกต์ ผู้เรียนทำขั้นโหลดและเรียกใช้ผ่านแชทได้

สถานะ PUBLISHED GUIDANCE / PLATFORM RUNTIME NOT TESTED

## เลือกชุดตามงาน

| ชุด | เหมาะกับ | แนวทางที่รวมไว้ |
| --- | --- | --- |
| Website | เว็บไซต์ข้อมูล Landing Page Portfolio หรืองานแนะนำบริการ | ลำดับเนื้อหา จุดเด่น การนำทาง และการกระทำหลัก |
| Dashboard | ดูข้อมูล สรุปผล เปรียบเทียบ ค้นหา และกรองรายการ | ขอบเขตข้อมูล ตัวชี้วัด กราฟเมื่อจำเป็น ตารางและสถานะ |
| App | ฟอร์มจอง Tracker Calculator หรือระบบจัดการรายการ | ลำดับการทำงาน ฟอร์ม Validation ผลลัพธ์ และการแก้/ลบรายการ |

แต่ละชุดพร้อมใช้ใน `profiles/` รวม workflow การทำงาน, template แบบโครงสร้างหน้าจอ และ Frontend UI Quality เดิมไว้ในไฟล์เดียว ขนาดประมาณ 11 KB โหลดเฉพาะชุดที่ใช้กับหน้าหรืองานนั้น

Template เป็นแนวทางจัดโครงสร้างและพฤติกรรมให้ AI นำไปปรับกับโค้ดจริง การแก้ MVP เดิมให้ใช้เฉพาะส่วนที่เกี่ยวกับ Wish ส่วนงานใหม่ใช้โครงสร้างตาม brief ของผู้เรียน

## Flow ของผู้เรียน

1. เปิดโปรเจกต์ที่มี MVP อยู่แล้ว หรือโปรเจกต์ว่างสำหรับงานใหม่
2. เลือก Website / Dashboard / App แล้วส่ง prompt โหลดจาก `PROMPTS.md`
3. AI ดาวน์โหลดไฟล์ชุดที่เลือกและสร้าง `PROJECT-SKILL.md` ที่ root ของโปรเจกต์
4. ตรวจว่าไฟล์มีเนื้อหาหลังบันทึกและ reload พร้อมส่วน template ที่ตรงกับชุดที่เลือก
5. ส่ง prompt เรียกใช้โดยระบุ `อ่าน PROJECT-SKILL.md` พร้อมงาน, Wish, ขอบเขต และเกณฑ์ผ่าน
6. ตรวจโค้ดที่เปลี่ยน Preview พฤติกรรมเดิม/ใหม่ และงานที่บันทึก
7. งานถัดไปในโปรเจกต์เดิมเรียกไฟล์เดิมได้ หากเริ่มแชทใหม่ให้สั่งอ่านไฟล์อีกครั้ง

ตัวอย่างระบบจองที่มีฟอร์มและรายการจอง เริ่มจากชุด App ได้ ส่วนหน้าแสดงยอดและตัวกรองของระบบเดียวกันเลือก Dashboard สำหรับงานหน้าดังกล่าว

## ไฟล์สำหรับครูและผู้ดูแล

- `PROMPTS.md` — คำสั่งโหลด คำสั่งเรียกใช้ และทางสำรอง
- `TEST_PROTOCOL.md` — เกณฑ์พิสูจน์การโหลด บันทึก อ่าน และนำไปใช้จริง
- `manifest.json` — รุ่น, URL ที่ตรึง commit, ขนาด และ SHA-256 ของแต่ละชุด
- `skills/professional-web/SKILL.md` — workflow กลางสำหรับแพลตฟอร์มที่อ่านและเขียนไฟล์ผ่าน AI
- `templates/` — โครงสร้าง Website / Dashboard / App
- `skills/frontend-ui-quality/SKILL.md` — checklist เดิมพร้อม Provenance คัดลอกจากแพ็กเดิมครบทุกไบต์
- `LICENSES/` — license ของแหล่งที่ checklist เดิมอ้างอิง
- `tools/build_profiles.py` — สร้างไฟล์พร้อมใช้จากต้นฉบับทั้งสามส่วนสำหรับผู้ดูแลชุดแจก

ผู้เรียนใช้ไฟล์พร้อมใช้ที่รวมคำแนะนำไว้แล้ว ผู้ดูแลสร้างรุ่นใหม่ด้วย `python tools/build_profiles.py` และตรวจ hash ก่อนเผยแพร่

## การเข้าถึงและสถานะหลักฐาน

Repository สำหรับแจกคือ `Anurog1112/project-skills` URL ของรุ่นที่ตรวจการเข้าถึงอยู่ใน `PROMPTS.md` และ `manifest.json`

การเปิด Raw URL จากฝั่งผู้ตรวจและเทียบ hash เป็นหลักฐานการแจกไฟล์ ส่วนความสามารถของ AI บนแพลตฟอร์มในการโหลด URL, สร้าง `.md`, อ่านไฟล์กลับ และใช้คำแนะนำ ต้องทดสอบตามเส้นทางที่ผู้เรียนใช้จริง

การเรียกใช้ในชุดนี้เกิดจาก prompt ที่สั่งอ่านไฟล์คำแนะนำและทำงานตามโจทย์ การค้นพบ Skill อัตโนมัติเป็น Test Case แยกใน protocol

หาก AI โหลด URL หรือบันทึก `.md` ไม่สำเร็จ ให้ใช้ prompt ทางสำรองที่วางเนื้อหาชุดที่เลือกลงในแชท แล้วบันทึกสถานะที่ตรวจได้จริง
